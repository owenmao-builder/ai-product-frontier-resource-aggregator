# AI 新闻重要性标准 v2.1 · 发布优先与中文重点

基础评分版本：`importance-v2`；关注策略：`release-priority-zh-briefs-v1` · 2026-09-17

分数回答的是“这条消息有多值得阅读和据此行动”。先看它是什么类型，再看它相对已有信息改变了什么。Agent、Harness、可插拔、可观测性等，只在对应新闻确实涉及这些能力时讨论；仅提及品牌、热度、标题长度和发布时间不直接加分。官方确认的大厂新模型或实质新技术架构发布有单独的优先加分。不预设任何产品是“套壳”。

## 四个共同维度

每项 0–5 分，总分为 `2 × (实质增量×30% + 实际影响×30% + 解释价值×20% + 决策价值×20%)`，保留一位小数。

| 维度 | 权重 | 核心问题 | 低分与高分的区别 |
| --- | --- | --- | --- |
| 实质增量 | 30% | 与前代、既有研究、同类方案或旧规则相比，新增了什么？ | 0 无新增事实；2 小改进；3 有意义的新结果；4 显著改变已有方案；5 有充分对照的重大跃迁 |
| 实际影响 | 30% | 谁受到影响，变化有多大、多持久？ | 0 无明确影响；2 有限人群；3 一个领域的明显影响；4 较广且持续；5 行业层面重大影响。负面事件同样可能重要 |
| 解释价值 | 20% | 是否帮助理解机制、事实关系、条件和取舍？ | 0 空泛；2 有事实但解释有限；3 解释清楚；4 有例证与限制；5 严谨且可迁移的新认识 |
| 决策价值 | 20% | 能否帮助试用、研究、选择、调整计划或避开问题？ | 0 无法判断；2 提供线索；3 帮助明确选择；4 可据此行动；5 关键决策信息完整 |

没有有效对照时，实质增量最高 2 分。未知事项写入“待确认”，不能编造理由。没有代码不自动扣分；研究、商业、政策各有自己的行动价值。

## 不同类型核查不同问题

| 类型 | 重点核查 |
| --- | --- |
| 模型进展 | 能力、成本、延迟与限制；同条件基线；开放范围；作者宣称与独立复现的区别 |
| 研究论文 | 新发现与已有研究的差别；方法、基线、消融与适用范围；只读摘要必须注明 |
| 产品更新 | 用户新能完成什么任务；旧流程改变了什么；可用人群、价格和限制 |
| 开发与基础设施 | 解决什么工程问题；接口、接入成本、运维收益和成熟度；只核查这项工具实际涉及的能力 |
| 商业与行业 | 交易主体、确认状态、规模和资金用途；资源、供给、客户及竞争格局的变化 |
| 政策与治理 | 权威来源、草案或生效状态、适用对象、时间与义务变化；表决通过不等于法律生效 |
| 安全与事故 | 影响范围、版本、实际损害、复现条件和缓解措施；公开案例数不等于发生率 |
| 分析与教程 | 新观点或可迁移经验；推理和实例是否支持结论；不要求必须发布新产品 |
| 其他 / 待分类 | 先确认消息性质与 AI 相关事实，避免凭模糊标题强行归类 |

## 发布优先级

关注分 = `min(10, 基础分 + 发布优先分)`。明确的大厂新模型、新模型版本或实质新技术架构发布，额外 **+1.0**，模型和架构同时出现也不叠加。需要已阅读材料中的官方发布依据、可验证短引文、正确的发布主体，以及至少 3/5 的实质增量。

产品接入旧模型、办公功能升级、融资、治理流程、第三方衍生模型、性能测试、传闻和预告不获得这项加分。发布时间与收录时间分别说明。若发布信息只是历史背景，新闻主事件是第三方评测，也不加分。

加分表达用户的阅读偏好，不提高证据等级。原有 8 分及以上的证据要求作用于**基础分**；例如基础 7.4 + 发布优先 1.0 = 关注分 8.4，仍可以明确标为证据 B。展开时同时显示基础分和加分依据。

## 中文阅读与验证范围

7 分及以上（包含 7.0）的消息显示中文标题和 2–4 条新闻重点：发布或发生了什么、相对变化、影响、限制。忠实保留模型名、数字口径与不确定性；不扩写为未核实的全文翻译。点“展开重点”直接阅读，详细评分依据再展开。

菜单栏默认显示本机日历的“今天”，也能切换全部或 7 分以上。规则修改只补当天的小组样例，保留历史标记。本轮新增核查 1 条今天收录的模型发布消息，提供 8 条今日中文重点；没有重跑历史新闻。新模型实际早于今天发布时会明确标出。

## 证据单独展示

- **A 充分**：关键判断有充分直接材料支持。官方来源只能证明它直接支持的事实，不能自动证明性能领先。
- **B 待验**：有原文依据，但关键收益、影响或适用范围尚有未验证部分。
- **C 不足**：只有标题或材料不足，处于待评估状态。不显示数字，也不按 0 分处理。

卡片直接显示字母及两个字的解释；悬停分数或展开评分依据可查看完整定义。「待评估」筛选对应 C 不足。等级说明的展示调整不修改已有评估或分数。

每个已评分条目保留四项理由、原文链接与短引文、相对变化和待确认事项。基础分 8 分及以上要求 A 级证据、明确对照以及至少两份不同 URL 的材料；其中应包含对照材料。基础分 9 分及以上还要求增量、影响各不低于 4。程序检查字段和引用是否来自已提供材料；材料质量和对照是否成立仍需编辑判断，链接数量本身不证明结论。

基础分档位是阅读提示：9–10 重大变化；8–8.9 高优先级；7–7.9 值得重点阅读；5–6.9 对相关人群有用；低于 5 通常较局部。它是编辑判断，不是科学测量或产品质量排行榜。

## 旧数据迁移与后续更新

所有旧规则分作废。旧数据按标题暂分类型；只有匹配当前标题、URL 和版本指纹的正文评估才能显示新分数。待评估条目可单独筛选。时间只用于排序；同 URL 去重，不声称已完成跨媒体事件合并。

初始版本核查 23 篇原文，包括官方公告、作者模型卡、论文摘要、社区原帖和媒体报道。当前附带材料均为 B 级，没有为凑高分将其升级到 A。论文摘要未当成已读全文，厂商自报性能与实际复现分开标注。

未配置模型时，应用显示随包附带的核查结果，其余保持待评估。设置中启用 AI 后，每轮只读取本机当天最多 5 条的公开正文，并尝试从已有 7 天数据中找相关历史对照。发送的是有限长度片段，截断会注明。引用、维度或高分条件不通过时保留待评估，失败或待评估结果 6 小时后可重试。历史检索是有限候选匹配，不能保证找到最佳竞品。
